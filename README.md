**A Python-powered programming language inspired by Lua, designed to offer more built-in features and functionality.**

I wanted to keep the simplicity and flexibility that make Lua enjoyable to use while taking things a little further by adding more built-in functions and features.

The main idea is to make programming more convenient by giving developers more tools right out of the box. Instead of having to rely on external libraries or write additional code for common operations, Lunar aims to provide more functionality directly within the language.

## Features

- **Lua-inspired syntax:** Keeps the simplicity and readability of Lua while allowing room for additional features.
- **Python-powered:** Built using Python, making it easier to develop and expand the language.
- **More built-in functions:** Provides additional functionality to make common programming tasks easier.
- **Simple and readable:** Designed to keep the code understandable without making the language unnecessarily complicated.
- **Flexible:** Aims to support different programming needs through its growing collection of built-in features.

Lua has always been an interesting language because of how simple and flexible it is. However, I wanted to explore what it would be like to have that same kind of simplicity while having more built-in functions available.

That's where Lunar comes in. It takes inspiration from Lua's design while using Python as its foundation to develop its own features and functionality.
